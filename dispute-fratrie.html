La règle du parent

  • Le parent guide, montre les étapes oubliées, clarifie ce qui aurait pu être fait différemment.
  • Il ne juge jamais, ne départage jamais, c'est le pire truc à faire. Il devient le méchant alors qu'à la base il n'avait rien à voir avec ça, et c'est le meilleur moyen pour créer de l'injustice, des "tu le préfères à moi" etc.
  • Si c'est trop chaud bouillant : l'adulte sépare les enfants, ils discutent ensuite tous ensemble.
  • L'adulte a le droit de dire : "Je vous laisse une dernière chance de trouver une solution, après j'enlève le jeu."
